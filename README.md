# 📖 Overview

**Android Dimen Resource Library** is a reusable Android `dimen.xml` resource collection designed to simplify Android UI development.

This library contains predefined `dp` and `sp` dimension values that help developers create consistent, responsive, and maintainable Android layouts without repeatedly writing manual dimensions.

The resource file includes:

- 📏 Dimension values from `1dp` to `1072dp`
- 🔤 Text sizes from `5sp` to `70sp`
- 📱 Responsive UI support
- ⚡ Faster XML development
- 🎨 Consistent Android design system

Perfect for:

- Android Developers
- UI/UX Designers
- Android XML Development
- Reusable Design Systems

# 📂 Example Usage

## XML Example

```xml
<TextView
    android:layout_width="match_parent"
    android:layout_height="@dimen/dim_50dp"
    android:textSize="@dimen/text_16sp"
    android:padding="@dimen/dim_12dp"
    android:text="Hello Android"/>
```

---

# 📂 Resource Examples

```xml
<dimen name="dim_10dp">10dp</dimen>
<dimen name="dim_20dp">20dp</dimen>
<dimen name="text_16sp">16sp</dimen>
<dimen name="text_24sp">24sp</dimen>
```

# ⚙️ Installation

## 1️⃣ Copy dimen.xml

Copy the `dimen.xml` file into:

```bash
app/src/main/res/values/
```

---

## 2️⃣ Use in Layout XML

```xml
android:padding="@dimen/dim_16dp"
android:textSize="@dimen/text_18sp"
```
